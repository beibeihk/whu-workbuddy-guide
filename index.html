01APPLY

在智慧珞珈提交申请

用武汉大学统一身份认证登录，在办事大厅找到由智慧校园部办理的「大模型API申请」。

  1. 智慧珞珈
  2. →
  3. 办事大厅
  4. →
  5. 大模型API申请
  1. 打开事项，点立即申请。核对系统带入的身份信息，补充联系邮箱与 API 用途。
  2. 用途写明实际任务、会处理什么材料，以及为什么需要调用 API。可以参考下方句子，按自己的研究改写。
  3. 点立即提交，保留系统默认的智慧校园部审核节点，确认提交。之后在「我的申请」看审批进度。

用途示例 · 按实际情况修改

用于公开政策文本和文献摘要的批量分类与信息提取。计划通过 API 对公开样本开展模型评测，并保留处理过程以便复现。

搜不到时，进办事大厅，在智慧校园部分类下找「大模型API申请」。公告里多了「服务」二字，搜索时用办事大厅里的短名称。

02GET KEY

审批通过后，复制自己的 API Key

登录武大大模型服务平台。在左侧「虚拟密钥」里找到状态正常的密钥，复制密钥值。如果平台已为你生成一条，直接用现有密钥。

03CONFIGURE

04TEST

卡住了怎么排查

申请提交后，平台里还没有密钥

先到办事大厅的「我的申请」查看办理进度。若已办结，核对两个平台是否登录同一个武大账号，再查看「虚拟密钥」。仍无可用密钥时，按平台提示联系智慧校园部。

WorkBuddy 的「测试连接」失败

对照上表检查接口地址、模型 ID 和密钥值，尤其注意不要粘贴多余空格或把模型展示名填成 ID。若返回 401，优先检查密钥；若提示限流或额度不足，到武大平台查看密钥状态、余额和模型权限。

连接测试成功，聊天时却没有回复

确认新任务选的是「自定义模型」里的 qwen-27b，再发一条无附件的短文本。若仍报错，记录错误提示，核对模型状态和用量。短文本跑通后，可分别测试图片、工具调用等任务所需的能力。
